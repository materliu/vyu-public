## 2026-10-26：选择视频封面（构建 15）

已完成的本机视频可在管理菜单中打开“选择封面”，拖动或按秒微调画面；取消不保存，保存后立即刷新列表并随重启保留，也可恢复自动封面。选帧不播放声音，保存前重新检查本机视频是否仍可用。云端未下载视频先保留下载入口，下载后才能选帧。

精确取帧不回退首帧。自动封面最多检查五个位置，遇到近全黑帧时继续尝试；纯黑视频保留可用画面。普通文件与系统离线包分别使用有界超时，旧自动缓存按需更新。

选帧位置沿用元数据同步。已归档视频只更新小型 JPEG 和版本标记，不重传视频本体；标记绑定图片 SHA-256，错序到达或冲突时不把旧图片认作新封面。保留账号、删除、路径、大小以及迟到结果检查。

首轮本地回归 **388 项全部通过、0 失败、0 跳过**：384 项单元与集成测试、4 项界面测试。包含黑红绿蓝合成视频的实际取帧颜色、自动避黑、取消与缓存竞态、持久化、模拟云同步，以及真实拖动选帧、取消、快速微调、重启、恢复自动封面和播放。公开网络与真实 iCloud 探针未启用。

补上图片与标记内容一致性修正后，最终相关复验 **45 项全部通过、0 失败、0 跳过**：43 项云端文件/同步/归档测试、2 项封面及云端恢复界面测试。新增用例验证另一张合法 JPEG 与新标记混合时隐藏错误图、修复及幂等，并验证旧标记升级。两次结果不相加为一次全量。合成 HTTP 服务另有 **22 项通过**。

本机有效团队、Bundle ID、签名方式、权限文件和版本设置与迁移前一致；有无本机覆盖文件时，生成的公开工程及 plist 字节一致。迁移当时真机源码编译和链接完成，但最后的证书签名返回 `errSecInternalComponent`，未生成已验证可安装的真机包。未修改的原配置对照同样失败；当时未调整钥匙串权限、账号或签名设置。构建 15 的后续签名与安装结果见上文。

公开工程不保存个人团队、账号、设备记录或本机路径。正常本机构建的签名覆盖保存在 Git 忽略的文件中；修改本机配置后，应重新核对有效构建设置，而不能只看 YAML。免费个人团队的本机模式与完整 iCloud 构建分开，前者不提供原生云同步。
