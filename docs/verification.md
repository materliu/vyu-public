## 构建与配置

公开配置在没有本机签名覆盖文件时，通过了禁用签名的 Release 模拟器编译检查。用于运行与测试的 ad hoc 签名另经核验；显式本机模式的产物含 `VYuICloudEnabled=NO`，不含 iCloud/ubiquity 签名权限。完整配置仍为 `YES`。

本次配置变更后的单元与集成回归共 **365 项全部通过、0 失败、0 跳过**，包括新增的配置解析、本机模式和合成云同步测试；明确排除了公开网络和真实 iCloud 探针。合成服务另有 **22 项全部通过**。本轮未重跑 UI 测试或安装手机。

本机有效团队、Bundle ID、签名方式、权限文件和版本设置与迁移前一致；有无本机覆盖文件时，生成的公开工程及 plist 字节一致。真机源码编译和链接完成，但最后的证书签名返回 `errSecInternalComponent`，未生成已验证可安装的真机包。未修改的原配置对照同样失败；未调整钥匙串权限、账号或签名设置，不能把这次结果描述为真机签名或安装成功。

公开工程不保存个人团队、账号、设备记录或本机路径。正常本机构建的签名覆盖保存在 Git 忽略的文件中；修改本机配置后，应重新核对有效构建设置，而不能只看 YAML。免费个人团队的本机模式与完整 iCloud 构建分开，前者不提供原生云同步。
