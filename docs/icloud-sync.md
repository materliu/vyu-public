# iCloud 视频同步

启用 iCloud 能力的正常构建在 App 启动及回到前台时检查账号和容器，并自动准备已有和新完成的合格视频。**当前没有 App 内的同步开关，也不是只在手动点击上传后才同步。** 上传由系统调度，只有系统报告所需文件上传完成，视频条目才显示“已同步到 iCloud”。

开发用 LocalOnly 是显式构建配置，用于不连接真实 iCloud 的本地开发；它不是正常构建中的用户开关。配置和签名说明见 [README](../README.md)。

## 使用方式

1. 使用具备有效 iCloud Documents 权限的 App，设备登录自己的 iCloud 账号并启用 iCloud Drive。
2. 在“离线”查看同步状态。合格的已完成视频会自动准备上传；“等待 iCloud 完成上传”不表示已经完成。
3. 在同一 iCloud 账号的其他设备打开 App，等待列表和预览图出现。轻点云端条目后才请求视频文件，校验通过后播放。
4. 需要重新检查账号、容器或失败的上传时，可在 iCloud 管理菜单中选择“重新同步”。

云端列表可先于视频文件下载出现。未点击恢复的视频不会自动复制到本机离线库。系统上传和下载的耗时受网络、云端空间及系统调度影响，不能承诺即时完成。

## 同步哪些内容

| 内容 | 行为 |
| --- | --- |
| 已验证的 MP4、MOV、M4V | 同步普通视频文件，包括符合条件的 HLS 导出结果和本机导入视频。 |
| 视频元数据 | 保存标题、来源域名、时长、音轨信息、日期、文件大小和用于完整性检查的摘要。 |
| 可用预览图 | 与视频记录一起保存。 |
| 自定义名称、收藏、标签和封面位置 | 对已进入云端归档的视频单独同步，不必重新上传视频文件。 |
| 系统 HLS `.movpkg` 包 | 不直接同步，见下文的重新获取流程。 |
| 原始媒体地址、签名参数、Cookie、登录凭据和下载恢复数据 | 不进入应用的 iCloud 文档同步。 |
| 浏览历史、网页收藏、观看位置、系统资产地址和 bookmark | 保留在本机，不进入此同步流程。 |

云端恢复会核对文件摘要及媒体可播放性。文件缺失、摘要不符或校验失败时不会把它加入可播放的离线库。来源仅保留域名，因此恢复后的“打开来源站点”不能还原原始视频页面或登录会话。

## HLS 视频的处理

HLS 是来源协议，不决定最终文件能否同步。支持的完整、未加密 fMP4 点播可生成普通 MP4；只有生成结果经过完整性与媒体校验后才允许同步。需要 Cookie 的 HLS 目前不支持离线保存。

已有 `.movpkg` 仍保留本机播放能力。iCloud 可用时，App 可重新请求原来源并尝试生成 MP4；视频菜单中的“准备 iCloud 同步”可显式重试。这个过程需要保持 App 在前台。

新 MP4 验证并保存成功后才替换旧包。原链接过期、格式不支持、取消或准备失败时保留原视频，不会自动反复重试；可回到原网页刷新来源后重新下载。能播放已有离线包，不表示仍能重新下载原来源。下载格式与前台限制详见 [视频下载](video-download.md)。

## 缓存、移除和删除

- **优化本地存储**：离线页“本地存储”中的独立开关，默认关闭，不会关闭 iCloud 同步。开启后，视频缓存超过 1 GB 时优先保留收藏，同类优先保留最近更新的内容；只释放已重新核验当前账号上传完成、内容一致的副本。已有本机视频副本的冗余 iCloud 驻留缓存先行释放。标题、收藏、标签、封面和观看位置保留，点击云端条目后下载播放。未同步或使用中的视频可能暂时超出目标；浏览资料、封面和同步临时空间另计。
- **删除本机缓存**：移除本机文件，保留已有云端副本。若尚未显示“已同步到 iCloud”，不要把这项操作当作已经完成云端备份。
- **移除视频记录／从本机列表移除**：移除当前设备的记录及适用的本机文件，已存在的云端视频保留；可通过“显示全部云端视频”重新显示。
- **从所有设备删除**：需确认，删除云端副本并记录删除标记。其他设备下次同步时处理对应删除；删除标记用于防止迟到的上传使条目重新出现。

跨设备变化不会保证即时传播。删除前应确认操作范围，尤其不要将“从所有设备删除”与仅清理缓存混淆。

## 账号变化与故障处理

检测到 iCloud 账号变化后会暂停同步，需确认继续使用当前账号。原账号的视频仍留在本机，并保持原账号归属，不会自动上传到新账号；对应的收藏和标签也不会被混入新账号。

当 iCloud 不可用或传输失败时，先检查设备账号、iCloud Drive、App 的 iCloud 权限、网络以及本机和云端空间，再选择“重新同步”。已保存的本机视频仍可离线播放。

“尚未同步到 iCloud”“等待 iCloud 完成上传”和“已同步到 iCloud”表示不同阶段。状态仍在等待或失败时，不能据此认为另一台设备已经可以恢复完整视频。

## 开发配置与验证边界

真机同步需要开发者自己的有效签名团队、Bundle ID、iCloud Documents 容器及描述文件。工程声明与最终签名权限必须一致；仓库配置不会授予其他开发者访问某个容器的权限。具体配置步骤见 [README](../README.md)。

使用临时目录的本地模拟测试可以验证归档、摘要校验、恢复、删除和账号隔离逻辑，不能证明 Apple 服务已收到文件，也不能代替真实多设备验收。

多设备验收应使用专门的测试资料：先确认源设备显示上传完成，再在另一台设备恢复，断网检查画面、声音、完整时长和拖动播放；还应分别覆盖网络中断、空间不足、重启、账号切换和删除传播。本文不承诺所有设备、系统版本或异常场景均已验收。
